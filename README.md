A machine learning–powered web application that analyzes user-submitted text and predicts the likely mental health state of the writer — **Anxiety, Depression, Suicidal, or Normal** — using Natural Language Processing (NLP) and a trained Support Vector Machine (SVM) classifier.

The goal of this project is to demonstrate how text analysis can support **early detection and awareness** of mental well-being, and to provide a full-stack example of taking an ML model from a Jupyter notebook into a deployed, user-facing web app.

🔗 **Live demo:** [mental-health-prediction-project-fdbg.onrender.com/](https://mental-health-prediction-project-fdbg.onrender.com/)

> ⚠️ **Disclaimer:** This application is an academic/portfolio project and **is not a diagnostic or medical tool**. Predictions are generated by a statistical model trained on a limited dataset and must not be used as a substitute for professional mental health advice, diagnosis, or treatment. If you or someone you know is struggling, please reach out to a licensed mental health professional or a crisis helpline in your region.

## ✨ Features

- **Text-based mental health classification** — enter free-form text and receive an instant prediction (Anxiety, Depression, Suicidal, or Normal).
- **NLP preprocessing pipeline** — lowercasing, punctuation removal, tokenization, stopword removal, and lemmatization applied to every input before prediction.
- **User authentication** — secure registration and login system with hashed passwords (Werkzeug) and session management.
- **MySQL-backed user store** — user credentials are persisted in a relational database.
- **Responsive web interface** — built with HTML/CSS/Bootstrap-based templates for a clean, modern user experience.
- **Production-ready deployment** — configured with `gunicorn` and a `Procfile` for deployment on platforms like Render/Heroku.

## 🤖 Machine Learning Pipeline

The full experimentation and training workflow is documented in [`mental_health.ipynb`](./mental_health.ipynb).

1. **Dataset** — a balanced text dataset of ~992 samples across four classes: `Anxiety`, `Depression`, `Normal`, and `Suicidal` (248 samples each).
2. **Text preprocessing** — lowercasing, punctuation removal, tokenization (`nltk.word_tokenize`), stopword removal, and lemmatization (`WordNetLemmatizer`).
3. **Feature extraction** — text is converted into numerical features using `TfidfVectorizer` (max 5,000 features).
4. **Model comparison** — several classifiers were trained and evaluated on an 80/20 train-test split:
   - Logistic Regression
   - Decision Tree
   - Random Forest
   - **Support Vector Machine (SVM)** ✅ *(selected as the final model)*
5. **Evaluation** — each model was assessed using accuracy score, classification report (precision/recall/F1), and confusion matrix visualizations.
6. **Serialization** — the final SVM model and TF-IDF vectorizer are exported with `joblib` as `svm1_model_nlp.pkl` and `tfidf1_vectorizer.pkl`, and loaded directly by the Flask app at inference time.

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- MySQL Server
- `pip` package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/farzeen-05/Mental-Health_Prediction-Project.git
   cd Mental-Health_Prediction-Project
   ```

2. **Create and activate a virtual environment** *(recommended)*
   ```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up the database** — see [Database Setup](#-database-setup) below.

5. **Configure environment variables**
   ```bash
   export DATABASE_URL="mysql://<username>:<password>@<host>:<port>/<database_name>"
   ```
   On Windows (PowerShell):
   ```powershell
   $env:DATABASE_URL="mysql://<username>:<password>@<host>:<port>/<database_name>"
   ```

6. **Run the application**
   ```bash
   python app.py
   ```
   The app will be available at `http://localhost:4000`.

## 🗄 Database Setup

The app requires a MySQL database with a `users` table. Run the provided schema:

```bash
mysql -u <username> -p <database_name> < mental.sql
```

This creates the following table:

```sql
CREATE TABLE `users` (
    `u_id` INT(11) NOT NULL AUTO_INCREMENT,
    `u_name` VARCHAR(255) NOT NULL,
    `email` VARCHAR(255) NOT NULL UNIQUE,
    `password` VARCHAR(255) NOT NULL,
    PRIMARY KEY(`u_id`)
)
```

Passwords are hashed with Werkzeug's `generate_password_hash` before being stored — plaintext passwords are never saved.
